# tpmp-lab2-task3

## Overview
Проект посвящен изучению структур данных на языке C и автоматизации сборки с помощью утилиты make. 
В рамках работы реализованы пользовательские типы данных и базовые операции с ними.

## Author

## Usage
Для компиляции проекта выполните:
make

Для запуска программы:
./app

Для очистки временных файлов:
make clean

## Additional Notes
Проект организован в соответствии с "A simple git branching model". 
Весь исходный код находится в папке src/.
